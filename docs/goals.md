# Цели и задачи

## Главная цель (SMART)

Разработать информационный ресурс **TelegramHelper** — Telegram-бота-ассистента для IT-команд из 3–15 человек, который позволяет
- поставить задачу на доску YouGile **одной фразой или голосовым** (≤ 30 секунд от сообщения до карточки),
- автоматически получать **саммари и список задач по записи встречи** (≤ 10 минут после окончания часовой встречи),
- проводить **ежедневные стендапы** с автоматическим выделением блокеров,

и сократить ручную работу руководителя по переносу задач и протоколированию встреч **не менее чем на 50 %**, к **07 ноября 2026 года**.

## Проверка по SMART

- **S (Specific):** конкретный продукт (Telegram-бот), конкретная ЦА (IT-команды 3–15 человек), три конкретные функции.
- **M (Measurable):** ≤ 30 с на создание задачи; ≤ 10 мин на обработку записи встречи; −50 % ручной работы руководителя (замер: время на протокол и перенос задач до/после).
- **A (Achievable):** используются готовые API (Telegram Bot API, YouGile, МТС Линк, LLM-провайдеры) и библиотеки (aiogram, Telethon, faster-whisper); ядро бота уже реализовано в рамках хакатона.
- **R (Relevant):** команды и так работают в Telegram — продукт убирает разрыв между перепиской и формальными инструментами.
- **T (Time-bound):** 07.11.2026 — защита практики.

## Задачи (декомпозиция)

1. Проанализировать предметную область, процессы команды и аналоги.
2. Собрать и приоритизировать функциональные и нефункциональные требования.
3. Спроектировать модель данных (пользователи, команды, задачи, встречи, обещания).
4. Спроектировать архитектуру: control-бот, userbot, LLM-агент, интеграции, хранилище.
5. Спроектировать сценарии диалогов бота для ролей «владелец», «директор», «участник».
6. Подготовить UML-диаграммы и документацию, проверить ключевые сценарии.

## Концепция ИР

**Назначение:** AI-ассистент, который превращает переписку, голосовые и записи встреч команды в структурированные задачи, напоминания и отчёты — не выходя из Telegram.

**ЦА:** руководители небольших IT-команд (директора/тимлиды), участники команд, а также отдельные специалисты с большим объёмом переписки (владельцы аккаунтов).

**Функции:**
- создание и управление задачами YouGile из чата текстом и голосом;
- встречи: создание комнаты, транскрипция записи, саммари, задачи с подтверждением;
- стендапы, блокеры с эскалацией, пульс-опросы, анализ тональности сообщений;
- обещания из переписки, напоминания, утренний и вечерний дайджест;
- поиск по переписке и саммари чатов, черновики ответов с подтверждением.

**Эффект:** задачи не теряются в чате; протокол встречи появляется автоматически; руководитель видит блокеры и риски выгорания раньше; рутина по переносу информации сокращается вдвое.

**Отличия от аналогов:** всё в одном Telegram-интерфейсе; управление на естественном языке и голосом; несколько LLM-провайдеров с автоматическим переключением при сбое (включая российский GigaChat); подтверждение любых действий, видимых другим людям.
