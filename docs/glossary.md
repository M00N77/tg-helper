# Глоссарий предметной области

| Термин | Определение |
|--------|-------------|
| **Владелец** | Пользователь, который подключил свой Telegram-аккаунт к ассистенту и управляет им через control-бота |
| **Control-бот** | Telegram-бот, через который владелец и команда отдают команды ассистенту (кнопки, команды, свободный текст, голос) |
| **Userbot** | Программный клиент, работающий от имени аккаунта владельца: читает его чаты, чтобы делать саммари, поиск и извлекать обещания |
| **Команда** | Группа пользователей, привязанная к одному групповому чату Telegram и (опционально) к канбан-доске |
| **Директор** | Роль в команде с расширенными правами: создаёт команду, утверждает задачи на других участников, настраивает интеграции |
| **Участник** | Член команды с базовыми правами: создаёт задачи себе, отвечает на стендапы и опросы |
| **Приглашение** | Запись о том, что пользователь приглашён в команду; при первом обращении к боту он автоматически становится участником |
| **Обещание (commitment)** | Договорённость из переписки со сроком: «моё» (я обещал) или «их» (обещали мне) |
| **Задача** | Карточка на канбан-доске YouGile с названием, описанием, исполнителем, колонкой и сроком |
| **Встреча** | Созвон команды (Jitsi / МТС Линк), запись которого транскрибируется в текст, саммари и список задач |
| **Стендап** | Ежедневный короткий отчёт участника: что сделал, что планирует, что мешает, настроение |
| **Блокер** | Препятствие, мешающее выполнить задачу; имеет уровень серьёзности и эскалируется руководителю |
| **Пульс-опрос** | Анонимный ежедневный опрос настроения команды по шкале 1–5 |
| **Дайджест** | Автоматическая сводка (утренняя / вечерняя / новостная): горящие обещания, задачи на завтра, ждущие ответа сообщения |
| **Интент** | Намерение пользователя, которое LLM-агент распознаёт во фразе на естественном языке (например, «создать напоминание») |
| **LLM-провайдер** | Внешний сервис языковой модели (OpenAI, Gemini, Groq, GigaChat), через который агент понимает текст |
| **Подтверждение действия** | Двухшаговый механизм: бот показывает черновик действия, видимого другим, и выполняет его только после нажатия «Подтвердить» |
