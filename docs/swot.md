# SWOT-анализ

| Strengths (сильные стороны) | Weaknesses (слабые стороны) |
|-----------|------------|
| 1. Всё в Telegram — не нужно ставить новое приложение и переучивать команду | 1. Нет веб-интерфейса и мобильного приложения — только бот |
| 2. Управление на естественном языке и голосом (LLM-агент + транскрипция) | 2. Зависимость от внешних LLM-API: стоимость запросов и задержки |
| 3. Несколько LLM-провайдеров с автоматическим переключением при сбое (OpenAI, Gemini, Groq, GigaChat) | 3. Один инстанс: встроенное векторное хранилище не масштабируется горизонтально |
| 4. Готовые интеграции: YouGile, МТС Линк, Jitsi | 4. Ограниченное время на развитие (4 недели) и небольшая команда разработки |
| 5. Безопасность: шифрование ключей и сессий, RBAC, подтверждение действий | 5. Поддерживается только одна канбан-система (YouGile) |

| Opportunities (возможности) | Threats (угрозы) |
|---------------|---------|
| 1. Рост удалённой работы и роли Telegram как рабочего мессенджера в РФ | 1. Изменение правил Telegram: userbot и авто-ответы — «серая зона» ToS, риск блокировки аккаунта |
| 2. Импортозамещение: спрос на решения с российскими сервисами (GigaChat, YouGile, МТС Линк) | 2. Ужесточение 152-ФЗ о персональных данных и требований к хранению переписки |
| 3. Подключение других досок (Яндекс Трекер, Kaiten) и календарей | 3. Конкуренция: встроенные AI-функции в Telegram, Яндекс Телемост, YouGile |
| 4. Командная монетизация (подписка на команду) и B2B-внедрения | 4. Рост цен или отключение зарубежных LLM-API для пользователей из РФ |
| 5. Развитие open-source LLM — можно перейти на локальные модели | 5. Недоверие компаний к ботам, читающим рабочую переписку |

## Выводы

- Использовать S1–S2 для захвата O1: позиционирование «ассистент, который живёт там, где уже живёт команда».
- Закрыть W2 и T4 через S3 + O2: приоритет российских провайдеров в цепочке, кэширование, лёгкие модели для простых запросов.
- Угрозы T1 и T5 снижаются прозрачностью: авто-ответ выключен по умолчанию, архивные чаты игнорируются, данные шифруются (см. [risks.md](risks.md)).
